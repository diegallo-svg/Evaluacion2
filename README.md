Proyecto de Geolocalización - Biblioteca Nacional

Este proyecto es una mejora del software de geolocalización utilizando la API de Graphhopper que permite a los usuarios buscar rutas entre dos ciudades, obteniendo la distancia, el tiempo de viaje y las instrucciones paso a paso

Para ejecutar este script, asegúrese de tener Python instalado y ejecute el comando desde la consola de visual Studio en un sistema operativo Linux:

python3 geolocalizacion.py
